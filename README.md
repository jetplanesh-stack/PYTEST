# 🐍 PYTEST - AI 파이썬 문제 풀이 앱

## 📋 프로젝트 소개

**PYTEST**는 초급부터 고급까지 **단계별로 파이썬을 배우는 학습 앱**입니다.
- 🤖 **AI가 생성한 문제**로 학습
- 📚 **체계적인 커리큘럼** (25개 주제)
- 👤 **개인별 학습 진도 관리**
- 🎮 **게임 방식의 레벨/경험치 시스템**

## 🎯 주요 기능

### 1. **문제 풀이** 💻
- **객관식 & 주관식** 문제
- **난이도별 선택** (초급 / 중급 / 고난도)
- **AI 피드백** 및 해설
- **효율성 채점** 및 개선 제안

### 2. **학습 경로** 📚
- **25개 주제** (초급 5 + 중급 5 + 고급 10)
- **선행 요구사항** 자동 표시
- **진행도 시각화** (숙련도 레벨)
- **추천 주제** 자동 제안

### 3. **사용자 관리** 👤
- **닉네임 + 비밀번호** 기반 인증
- **개인별 진행도 저장**
- **SHA-256 암호화** 보안
- **로그인 / 로그아웃**

### 4. **게임 시스템** 🎮
- **레벨 & 경험치 (XP)**
- **티어 업** (Beginner → Student → Expert)
- **효율성 등급** (1~9등급)
- **문제 풀이 기록**

## 📁 프로젝트 구조

```
project1_pytest_app/
├── app.py                    # 메인 애플리케이션
├── auth.py                   # 사용자 인증 & 데이터 관리

├── requirements.txt          # 패키지 의존성

```

## 🚀 시작하기

### 1. **설치**
```bash
pip install -r requirements.txt
```

### 2. **앱 실행**
```bash
streamlit run app.py
```

### 3. **브라우저 접속**
```
http://localhost:8501
```

## 📖 사용 가이드

### 첫 사용자 (회원가입)
1. "📝 회원가입" 탭에서 닉네임과 비밀번호 입력
2. 회원가입 버튼 클릭
3. 자동으로 로그인되어 메인 앱 시작

### 기존 사용자 (로그인)
1. "🔓 로그인" 탭에서 닉네임과 비밀번호 입력
2. 로그인 버튼 클릭
3. 이전 학습 진행도 로드

### 문제 풀이
1. **"💻 문제 풀이"** 버튼으로 이동
2. 왼쪽 사이드바에서 **문제 종류** 선택
   - 객관식 (4개 선택지)
   - 주관식 (직접 코드 작성)
3. **난이도** 선택
   - 초급: 기본 개념
   - 중급: 문제 해결
   - 고난도: 알고리즘
4. **"새 문제 출제"** 클릭
5. 문제 읽고 풀기
6. **"제출"** 버튼으로 채점
7. AI 피드백 및 개선안 확인

### 학습 경로 확인
1. **"📚 학습 경로"** 버튼으로 이동
2. **전체 진행도** 확인
   - 전체 주제 수
   - 완료율
   - 학습 중인 주제 수
3. **난이도별 모듈** 확인
   - 🟢 초급
   - 🟡 중급
   - 🔴 고급
4. 각 주제의 **진행 상태** 확인
   - 🔒: 선행 주제 미완료
   - ⭕: 시작 가능
   - 🟡: 학습 중
   - 🟢: 기초 이해
   - 🔵: 중급 진행
   - ⭐: 숙련 달성

## 📊 데이터 저장 위치

### users.json
- 모든 사용자의 닉네임과 비밀번호 해시 저장
- 사용자 생성 시간 기록

### user_data/{nickname}/progress.json
- 개인별 학습 진행도
- 누적 XP, 문제 해결 수
- 각 주제별 숙련도
- 문제 풀이 이력

```json
{
  "xp": 1250,
  "solved": 42,
  "history": [...],
  "topic_mastery": {...},
  "current_topic": null
}
```

## 🎮 게임 메커니즘

### XP & 레벨
| 문제 종류 | 초급 | 중급 | 고난도 |
|---------|------|------|--------|
| 객관식 | 10 XP | 20 XP | 35 XP |
| 주관식 | 20 XP | 40 XP | 70 XP |

### 티어 시스템
- 🟢 **Beginner** (Lv. 1~4): 기초 학습
- 🟡 **Student** (Lv. 5~9): 심화 학습
- 🔴 **Expert** (Lv. 10+): 고급 알고리즘

### 효율성 등급 (주관식만)
- **1등급**: 최고 효율 (모범 답안 수준)
- **5등급**: 평균
- **9등급**: 최저 효율

## 🔒 보안

- ✅ SHA-256 해싱으로 비밀번호 보호
- ✅ 각 사용자 데이터 격리
- ✅ 평문 비밀번호 저장 안 함
- ✅ 닉네임 중복 체크

```
초급 5개 주제 → 중급 5개 주제 → 고급 10개 주제
```

```
변수 기초
  ↓
문자열/리스트 → 조건문 → 반복문 → 함수
  ↓
딕셔너리 → 컴프리헨션 → 정렬 → 알고리즘
  ↓
재귀 → DP → 그래프 → ...
```
